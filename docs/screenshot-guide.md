# ClawdSnip 0.4.1

## 截图保存
宠物菜单里的“保存截图”可独立开关，也可在“设置…”中勾选“截图后选择保存到文件”。开启后，框选截图、窗口截图完成时弹出 PNG 保存窗口，可选文件名和文件夹。取消保存仍会复制图片；自动粘贴由原来的独立开关决定。

## 长截图
1. 宠物菜单或菜单栏选择“长截图…”。
2. 选择屏幕，框选需要滚动的内容区域，避开浏览器工具栏、固定页头、视频等动态内容。
3. 手动缓慢向下滚动，每次留一些重叠内容，并稍停等画面稳定。控制条会显示采集尺寸。
4. 点“完成”查看长图预览。本次可单独选择保存到文件和自动粘贴，再点“使用这张图”。

重复画面不会重复拼接；反向滚动或重叠不足时保留已有内容，请回到上次成功位置后慢慢下滚。最多 4000 万像素、30000 像素高度，到达上限会生成已采集部分的预览。

设置里可以为“长截图 / 完成采集”绑定快捷键，默认不占用新组合键。原有快捷键、登录启动及隐藏偏好继续保留。

录屏权限由 macOS 管理。临时签名更新后若出现已授权却仍被拒绝，需移除旧条目，重新添加实际安装的 ~/Applications/ClawdSnip.app 并开启。
